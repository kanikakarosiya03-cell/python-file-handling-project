# Python File Handling Project

A simple, interactive Python application for creating, reading, updating, and deleting files. This project was developed as part of my Python learning journey to gain practical experience with file handling, functions, modular programming, and error handling.

## About the Project

The **Python File Handling Project** provides a user-friendly interface for performing basic file operations. Instead of relying entirely on the command line, users can interact with the application through a simple UI to manage their files.

The main goal of this project was to apply Python concepts in a practical way and understand how different parts of an application work together.

## Features

* **Create Files:** Create new files through the application.
* **Read Files:** View the contents of existing files.
* **Update Files:** Modify the contents of files.
* **Delete Files:** Remove files when they are no longer needed.
* **Interactive Interface:** Perform file operations through a simple user interface.
* **Error Handling:** Handle common errors that may occur during file operations.

## Technologies Used

* **Python** — Core programming language
* **File Handling** — Reading, writing, and managing files
* **Functions** — Organizing code into reusable blocks
* **Modular Programming** — Separating application logic across multiple Python files
* **Interactive UI** — Providing a user-friendly way to interact with the application

## Getting Started

Follow these steps to run the project on your local machine.

### Prerequisites

* Python 3.x installed on your system
* A code editor, such as VS Code

### Installation

**1. Clone the repository**

```bash
git clone <your-repository-url>
```

**2. Navigate to the project directory**

```bash
cd python-file-handling-project
```

**3. Run the application**

```bash
python main.py
```

*Note: The commands above assume that `main.py` is the entry point of the application.*
